# enhance_social_insurance_x_explanations.py

`enhance_other_subject_x_explanations.py`와 같은 개념(함정 표현이 포함된 지문의 해설 후속 보정)을 **사회보험법** 한 과목에 대해 적용하는 스크립트. 과거 여러 백업 버전(`PREVIOUS_WITH_BASIS`: 근거 조문을 제거하기 전 버전, `DIRECT_SOURCE_DOC`: 최초 보강 직전 백업)을 참조 소스로 명시해두고 있다 — 문서가 여러 차례 편집을 거치며 그 중간 산출물들을 되짚어 참고해야 했던 이력을 보여준다.

파일: `scripts/enhance_social_insurance_x_explanations.py`
대상: `~/Desktop/1차 시험/#STD/260416/[doc] social_insurance_law_OX_integrated_2026_v1.docx`

## CLI

```bash
python3 scripts/enhance_social_insurance_x_explanations.py
```
