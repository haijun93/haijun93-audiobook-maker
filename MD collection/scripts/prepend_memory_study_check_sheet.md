# prepend_memory_study_check_sheet.py

`build_35day_first_exam_master_guide.py`가 만든 마스터 학습 가이드(`MASTER_GUIDE`)의 내용을 요약해, 4과목(`SUBJECT_DOCS`) 각 문서 **맨 앞**에 "암기 확인 시트"로 붙여 넣는 스크립트. `WD_BREAK`로 페이지 구분을 넣어 본문과 분리한다.

파일: `scripts/prepend_memory_study_check_sheet.py`

## CLI

```bash
python3 scripts/prepend_memory_study_check_sheet.py
```
