# ChatGPT Web Service Book Metadata Query & SOP Guide

본 문서는 `/Users/hyeokjunkong/Desktop/소설2/[k]` 폴더 내의 모든 EPUB 소설 도서에 대해, ChatGPT 웹서비스(또는 웹 기반 AI API)를 활용하여 5대 필수 서지 정보를 독립적으로 조회하고 유지 관리하기 위한 표준 작업 절차(SOP)입니다.

---

## 1. 개요 및 목적

소설 수장고 내의 각 작품에 대해 단순 제목과 저자명을 넘어, 독자가 한눈에 직관적으로 파악할 수 있도록 5가지 핵심 항목을 ChatGPT에게 질문하여 추출합니다.

### 🎯 ChatGPT 웹서비스 필수 질의 항목 (5가지)
1. **책의 대표 장르** (예: 미스터리/스릴러, 다크 로맨스, SF, 판타지, 역사 소설 등)
2. **최초 발간 연도** (예: 2021년)
3. **10문장 이내의 책 줄거리 개요** (핵심 몰입 요소 및 서사 요약)
4. **책을 특징짓는 핵심 키워드 5개** (예: `#기억상실, #스릴러, #이중인격, #반전, #추리`)
5. **책 평점** (5점 만점 기준)

---

## 2. 파일별 독립 질문 프롬프트 템플릿 (ChatGPT Web Prompt Template)

ChatGPT 웹서비스 대화창에 파일 1개당 독립된 세션으로 질문을 입력할 때 사용하는 표준 프롬프트 규격입니다.

```text
다음 소설 책 정보를 바탕으로 정확한 서지 정보와 줄거리 개요 5가지를 제공해 주세요.

[책 기본 정보]
- 책 제목: {title}
- 작가명: {author}

[질문 및 요청 사항]
1. 책의 대표 장르 (예: 다크 로맨스, 미스터리/스릴러, SF, 판타지 등)
2. 최초 발간 연도 (예: 2021년)
3. 10문장 이내의 책 줄거리 개요 (줄거리를 요약하되 핵심적인 몰입 요소를 다룰 것)
4. 책을 특징짓는 핵심 키워드 5개 (쉼표로 구분)
5. 책 평점 (5점 만점 기준, 예: 4.25 / 5.0)

[답변 형식 (JSON 규격)]
{
  "genre": "대표 장르",
  "published_year": "발간 연도",
  "synopsis": "10문장 이내 줄거리 개요...",
  "keywords": ["키워드1", "키워드2", "키워드3", "키워드4", "키워드5"],
  "rating": "4.25 / 5.0"
}
```
